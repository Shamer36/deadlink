# Deadlink
Vibe-coded site with underground music artists. and just a cool game project.

Русскоязычный сайт-игра про интернет-андер и электронику: диггинг конвертов, дропы, полка, карта сцен, граф связей, небо жанров и свой блок с зданиями.

## Как устроено
- `index.html` — весь сайт (одна страница).
- `login.html` — вход и регистрация.
- `server.py` — локальный сервер на Python (без зависимостей): отдаёт сайт, хранит базу в `data/db.json`, аккаунты в `data/accounts.json`, медиа в `media/` и `_blob/`, раз в минуту подтягивает обновления из этого репозитория.
- `ЗАПУСК.bat` — запуск на Windows. `ТУННЕЛЬ.bat` — публичный адрес через tuna.am.

Данные (`data/`, `media/`, `_blob/`) в репозиторий не попадают.
