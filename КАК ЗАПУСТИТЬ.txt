DEADLINK — локальная версия

Запуск
1. Нужен Python 3 (https://www.python.org/downloads/). При установке поставь галочку "Add python.exe to PATH".
2. Дважды кликни ЗАПУСК.bat. Откроется окно с текстом "Deadlink работает" и браузер на http://localhost:8000
3. Пока пользуешься сайтом, окно не закрывай. Закрыл окно — сайт выключился.

Что где лежит
index.html      — сам сайт
server.py       — маленький сервер: отдаёт сайт и сохраняет все изменения в эту папку
data/db.json    — вся база: артисты, релизы, связи, места, правки и твоя полка (data/users/local)
data/backups/   — копия базы раз в день, появляется сама
media/          — обложки и клипы по папкам: media\Артист\Релиз\обложка.jpg и Трек.m4a
_blob/          — свежие файлы, которые сервер ещё не разложил (раскладывает сам при запуске)
data/media.json — список, какой файл к какому релизу относится (не трогай)
data/accounts.json — учётные записи: логины, зашифрованные пароли, сессии и права админа (не трогай)

Всё, что меняешь на сайте (полка, новые артисты, загруженные обложки и треки), сохраняется сюда же.
Для переноса на хостинг понадобится вся эта папка целиком.

Важно: открывай сайт только через ЗАПУСК.bat, а не двойным кликом по index.html. Без сервера он не увидит базу.

Аккаунты
При открытии сайта сначала появляется вход. Первый, кто зарегистрируется, получит весь прогресс, который был до появления аккаунтов (полку, соус, дрип).
У каждого аккаунта своя полка и свой прогресс. Менять общую базу (вкладка «Добавить»: артисты, релизы, обложки, связи) могут только администраторы.
Пароль можно сменить под логотипом: «пароль». Там же «выйти».

GitHub
Код сайта лежит в https://github.com/Shamer36/deadlink. Папка DEADLINK подключена к нему (запусти один раз ПОДКЛЮЧИТЬ GITHUB.bat).
Пока работает ЗАПУСК.bat, сервер раз в минуту проверяет GitHub и сам подтягивает новую версию сайта. Если поменялся server.py, сервер сам перезапустится.
В GitHub попадают только файлы сайта. Папки data, media и _blob (база, аккаунты, обложки, треки) остаются только на компьютере.
